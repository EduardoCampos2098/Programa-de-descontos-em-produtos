📝 Programa de descontos.

Este projeto feito em Python visa facilitar a vida de um lojista que precisa aplicar descontos de forma meticulosa e rápida! 

O programa usa as condições: 5% OFF para compras até 199,99 R$; 10% OFF de 200 R$ a 299,99 R$; 15% OFF para quaisquer compras acima de 300 R$.
Após o inserimento do valor, o programa passa a informação por três condições de valores, a fim de porcurar aquela que se encaixa. No final ele retorna tanto o valor isolado do desconto, quanto o total a ser pago com o desconto.
